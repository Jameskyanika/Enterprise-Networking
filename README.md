## Troubleshooting Method

1. Identify the affected system or service.
2. Verify physical and local network connectivity.
3. Test the gateway and remote destinations.
4. Measure packet loss and latency.
5. Check switches, firewall policies and ISP links.
6. Escalate with technical evidence where necessary.
7. Retest after corrective action.
8. Confirm service restoration.
